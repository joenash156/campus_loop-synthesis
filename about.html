About CampusLoop

A practical campus platform with a community purpose.

CampusLoop combines a student marketplace with a thoughtful Lost & Found workflow.

Marketplace

Keep useful things in circulation.

Students can list items they no longer need, browse nearby listings, save products, and contact sellers directly.

Lost & Found

Return belongings without oversharing.

Sensitive information is intentionally withheld so a claimant can prove ownership before an item is returned.

Demo limitation

Frontend-only means local, not private.

This project uses HTML, CSS, JavaScript, and localStorage. Data stored in the browser can be inspected, so the sensitive-item workflow is a UX demonstration rather than real secure storage.
